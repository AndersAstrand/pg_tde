# Akeyless KMIP server configuration

`pg_tde` is compatible with the Akeyless Platform via the KMIP Server built into the Akeyless Gateway. For setup, see [Akeyless KMIP Server :octicons-link-external-16:](https://docs.akeyless.io/docs/kmip-server).

For more information on adding or modifying the provider, see the [Add or modify KMIP providers](../functions.md#add-or-modify-kmip-providers) topic.
